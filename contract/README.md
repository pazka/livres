# Contract with "Ma liseuse"

Golden responses, generated by `tests/test_contract.py` and copied into the app's tests
(`pazka/kindle-for-mom`), so a format change breaks CI on both sides.

| File | Endpoint |
|---|---|
| `catalog.json` | `GET /opds/v2/catalog.json` (OPDS 2.0 navigation, templated `search` link, `download-hosts` link) |
| `search-page1.json`, `search-page2.json` | `GET /opds/v2/search?query=…&page=N` (publications, `next`/`previous`) |
| `request-202.json` | `POST /api/v1/requests` accepted |
| `request-400-*.json` | `POST /api/v1/requests` refused: `error` is a full French sentence shown to Mom as is |

Other endpoints: `GET /api/v1/download-hosts` → `{"hosts": [...]}` (the only hosts the app may download
from), `429` with a French `error` when rate-limited, `401` when install tokens are enforced and the token
is unknown.

Rules: **additive changes only** (new optional fields). `identifier` is stable (`<source>:<id>`).
Acquisition links are ordered EPUB, MOBI, PDF; `properties.size` is present when the source gives it.
A breaking change means a new `/opds/v3` path, agreed with the owner.
